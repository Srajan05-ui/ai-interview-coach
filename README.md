# MockMate AI

AI Interview Coach built using Next.js, OpenRouter, Supabase and Tailwind CSS.

## Features

- Resume Upload
- Resume Analysis
- AI Interview Question Generation
- Answer Evaluation
- Learning Roadmap
- Interview History
- Score Tracking
