# MockMate AI – AI Interview Coach

## Project Description

MockMate AI is an intelligent interview preparation platform that helps students and job seekers improve their interview performance through AI-powered analysis and personalized feedback.

The application allows users to upload their resume, automatically extracts and analyzes resume content, identifies important skills, and generates customized interview questions based on those skills. Users can answer the generated questions and receive detailed AI-based evaluations, including scores, strengths, weaknesses, and improvement suggestions.

Based on interview performance, MockMate AI also creates a personalized learning roadmap to help users strengthen weak areas and improve their technical and communication skills. The platform stores interview history and performance data, allowing users to track their progress over time.

The project is built using Next.js, TypeScript, Tailwind CSS, OpenRouter AI models, Supabase, PDF/DOCX parsing libraries, and modern web technologies to provide a complete AI-powered interview coaching experience.

## Key Features

- Resume Upload (DOCX)
- Resume Analysis and Skill Extraction
- AI-Powered Interview Question Generation
- Answer Evaluation and Scoring
- Strength and Weakness Analysis
- Personalized Learning Roadmap
- Interview History Tracking
- Responsive Modern UI
- Database Integration with Supabase

## Project Workflow

1. User uploads resume
2. Resume is analyzed and skills are extracted
3. AI generates interview questions based on skills
4. User answers interview questions
5. AI evaluates answers and provides feedback
6. Scores and weak areas are identified
7. Personalized learning roadmap is generated
8. Interview history is stored for future reference
